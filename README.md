# Coaxial-Cable-2.4-GHz
# Моделирование коаксиальной линии передачи

В данном репозитории представлены результаты проектирования, аналитического расчета и трехмерного электромагнитного моделирования коаксиальной линии передачи. Основная цель проекта — синтез геометрии кабеля под заданное волновое сопротивление и анализ его характеристик на рабочей частоте 2.4 ГГц.

## 1. Аналитический расчет параметров

Первоначальный математический расчет физических размеров (внутреннего и внешнего диаметров) и волнового сопротивления с учетом параметров заполняющего диэлектрика (ε = 2.1). Расчетное волновое сопротивление линии составляет 53 Ом.

![Аналитический расчет](Coaxial%202.4%20GHz/image_2026-08-01_09-45-03.png)

## 2. 3D-модель

Геометрическая твердотельная модель коаксиальной структуры, подготовленная для проведения полноволнового электромагнитного анализа в САПР.

![3D-модель](Coaxial%202.4%20GHz/image_2026-08-01_13-18-02.png)

## 3. Результаты электромагнитного моделирования

### 3.1. Согласование и импеданс

Оценка качества согласования линии передачи. На центральной рабочей частоте 2.4 ГГц значение КСВН (VSWR) составляет 1.138, что подтверждает высокую точность предварительного расчета геометрии.
