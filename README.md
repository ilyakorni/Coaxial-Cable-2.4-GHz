# Coaxial-Cable-2.4-GHz
В данном репозитории представлены результаты проектирования, аналитического расчета и трехмерного электромагнитного моделирования коаксиальной линии передачи. Основная цель проекта — синтез геометрии кабеля под заданное волновое сопротивление и анализ его характеристик на рабочей частоте 2.4 ГГц.
